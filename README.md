# PayFlow

A payment operations dashboard for monitoring revenue, transactions and customers. Built with Next.js, React, TypeScript and Tailwind CSS, and structured the way real fintech product dashboards are.

> Frontend only: there is no backend in this version, and the data shown is sample data.

## Features

- Dashboard with revenue and payment statistics and recent payments
- Payment search and status filtering
- Customer search and customer details
- Profile and notification settings
- Login, signup and forgot-password pages
- Responsive sidebar and mobile menu
- Loading and 404 pages

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS, Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`

## Status

Frontend complete. Backend integration is not included in this version.
